## 1. Ниша проекта и её объём

### Ниша
Все-в-одном система для создания и управления веб-присутствием:
- Генерация статического сайта (SSG на Astro.js)
- Хостинг (Cloudflare Pages / GitHub Pages)
- Производство графики и видеопревью
- Анализ рынка и маркетинг

**Целевой пользователь:** разработчик-одиночка, фрилансер, малый бизнес или креатор, который хочет единую экосистему вместо 5+ разрозненных инструментов.

### Объём рынка (Jamstack / SSG)
- Рынок Jamstack-архитектуры: ~$2.5–3 млрд (2024), CAGR 15–20% до 2028.
- Astro.js — самый быстрорастущий SSG, лидер по удовлетворённости разработчиков (State of JS 2024).
- Рост упоминаний "Jamstack" и "Astro" в вакансиях: +40% год к году.
- Ниша "всё в одном для веб-присутствия" слабо занята — существующие решения покрывают только отдельные домены.

### Косвенные конкуренты

| Конкурент | Покрытие | Разрыв с Architect |
|-----------|----------|-------------------|
| **Webflow** | Визуальный билдер + хостинг | Закрытый, дорогой ($14–39/мес), не для разработчиков |
| **TinaCMS** | Визуальный редактор контента | Нет хостинга, нет аналитики, нет маркетинга |
| **Decap CMS** | Git-based CMS | Только управление контентом |
| **Carrd** | Одностраничные сайты | Крайне ограничен, не ASTRO/SSG |

### Главный вывод по конкурентам
**Ни один прямой конкурент не предоставляет:**
- Встроенную генерацию превью/графики для соцсетей и блога
- Модуль анализа рынка (конкуренты, тренды, семантика)
- Маркетинговую автоматизацию (контент-план, SEO-аудит)

Это и есть ключевое **конкурентное преимущество Architect**.

## 5. Тренды и возможности

### Тренды 2025–2026
1. **Astro.js захватывает лидерство** — с 2024 года самый популярный SSG по удовлетворённости. Все проекты на нём.
2. **Jamstack 2.0** — переход от "просто статики" к гибридным подходам (SSR + SSG + Edge Functions).
3. **Рост "indie maker" культуры** — соло-разработчики и микрокоманды создают 2-3 проекта в месяц.
4. **Self-hosted / open-source возвращение** — усталость от платных подписок; разработчики ищут контроль.
5. **AI-генерация контента** — автоматизация превью, описаний, мета-тегов.
6. **Edge-вычисления** — Cloudflare Workers, Vercel Edge — снижают затраты на инфраструктуру.

### Возможности для Architect
- **Заполнить пробел**: ни один конкурент не даёт "сайт + графика + маркетинг" в одной установке.
- **Бесплатный хостинг**: Cloudflare Pages — неограниченная полоса, 500 билдов/мес — идеально для MVP.
- **Self-hosted модель**: привлекает аудиторию, которая устала от Vercel/Netlify price hikes.
- **Российский рынок**: низкая конкуренция в нише Jamstack-инструментов на русском языке.

## 6. Рекомендации по позиционированию и УТП

### Позиционирование
> "Architect — единственная открытая платформа, которая объединяет создание сайта, хостинг, генерацию графики и маркетинговую аналитику в одном CLI и одном дашборде. Для разработчиков и креаторов, которые хотят контролировать свой стек, а не платить за 5 подписок."

### УТП (Unique Selling Propositions)

1. **Всё в одном** — SSG (Astro.js) + хостинг (бесплатный CDN) + генерация превью + аналитика рынка + маркетинг. Никаких 5+ инструментов.
2. **Self-hosted / open-source** — полный контроль над данными. Никаких price hikes и vendor lock-in.
3. **CLI-first + API** — для разработчиков, которые автоматизируют всё. Config-as-code, CI/CD-ready.
4. **Бесплатный порог входа** — Cloudflare Pages + GitHub Actions = $0 для старта.
5. **Автоматизация графики** — превью для соцсетей, Open Graph, YouTube — генерируются из шаблонов при каждом билде.

### Каналы продвижения
- **X/Twitter** — #buildinpublic, indie maker community
- **Telegram** — русскоязычное dev-сообщество
- **Dev.to / Habr** — статьи "Как я собрал все инструменты в один"
- **GitHub** — open-source repository с активным README
- **Product Hunt** — при запуске

### Рекомендуемые метрики успеха (KPI)
- Запуск MVP: 2 недели
- Первые 100 звёзд на GitHub — 1 месяц
- Первые 10 активных установок — 2 месяца
- Первые 5 проектов, развёрнутых через Architect — 1 неделя после релиза

## 7. Резюме (Executive Summary)

**Проект Architect** находится в растущей нише ($3B+, CAGR 15–20%) с чётким конкурентным разрывом: ни один существующий продукт не объединяет статический сайт, графику, аналитику рынка и маркетинг в одной системе.

**Целевая аудитория** — разработчики-одиночки, фриланс-дизайнеры и технические основатели, которые:
- тратят $50–150/мес на разрозненные инструменты,
- теряют 2+ дня на boilerplate новых проектов,
- хотят self-hosted open-source контроль.

**Рекомендуемая стратегия:** MVP с базовым функционалом (Astro.js + хостинг + шаблон превью + базовый отчёт) → итеративное добавление аналитики рынка и маркетинговой автоматизации на основе обратной связи первых пользователей.
