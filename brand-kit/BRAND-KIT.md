# Brands Kit — Architect

## Логотип

| Формат | Файл | Назначение |
|--------|------|-----------|
| SVG | `logo.svg` | Основной логотип (сайт, презентации, документы) |
| PNG 1200×360 | `logo-1200x360.png` | Hero-секции, большие экраны |
| PNG 600×180 | `logo-600x180.png` | Шапка сайта, презентации |
| PNG 300×90 | `logo-300x90.png` | Миниатюры, email-подписи |
| SVG | `favicon.svg` | Упрощённый значок, вкладки браузера |
| ICO | `favicon.ico` | Favicon для старых браузеров |
| PNG 192×192 | `favicon-192x192.png` | Android / PWA |
| PNG 64×64 | `favicon-64x64.png` | macOS / iOS (малый) |
| PNG 32×32 | `favicon-32x32.png` | Windows / стандартный |

### Правила использования
- **Минимальный отступ:** 40px со всех сторон (эквивалент высоты буквы «A»)
- **Не изменять пропорции** — всегда соотношение 10:3 (логотип) / 1:1 (favicon)
- **Не накладывать** на изображения/текстуры без белой подложки
- **Не менять цвет** — только фирменный градиент (#7c3aed → #a78bfa)
- **Чёрно-белая версия:** invert(1) в CSS или grayscale при печати

## Шаблон превью для статей/соцсетей

**Файл:** `article-preview-template.svg` (1200×630 — стандарт Open Graph)

### Как использовать
1. Откройте SVG в Figma, Illustrator или любом редакторе
2. Замените текст: название статьи, описание, категорию
3. Экспортируйте в PNG для соцсетей

| Зона | Что редактировать |
|------|------------------|
| Бейдж | Категория: СТАТЬЯ / НОВОСТЬ / ГАЙД / КЕЙС |
| Заголовок | Название материала (макс. 2 строки) |
| Описание | Краткое описание (до 200 символов) |
| Автор | Имя автора / название команды |
| Время чтения | Длительность в минутах |

## Плейсхолдер видео-интро

**Файл:** `video-intro-placeholder.svg` (1920×1080, 16:9)
**Превью:** `video-intro-placeholder.png` (960×540)

Временный placeholder для видео-интро / промо-ролика. Содержит:
- Фирменный фон с сеткой и архитектурными блоками
- Логотип, заголовок, подзаголовок
- Стилизованный play-кнопку и шкалу времени
- При необходимости: заменить на полноценный видео-ролик в DaVinci Resolve / Manim

## Анимации
- **Duration:** 150ms (micro-interactions), 300ms (transitions)
- **Easing:** `cubic-bezier(0.4, 0, 0.2, 1)` — стандартная Material
- **Entries:** fade-in + translateY(12px)
