**Проект:** Architect
**Автор:** PM (ecdaa85f)
**Связано:** DUN-134 / Лид-магнит 1

---

## Как использовать

1. Отмечайте каждый шаг по мере выполнения
2. Среднее время прохождения: 2–4 часа
3. Бюджет на весь стек: ~$13.50/мес

---

### Шаг 1: Домен + Cloudflare

- [ ] Купить домен (namecheap / reg.ru / любой) ~$10–15/год
- [ ] Подключить к Cloudflare (бесплатно)
- [ ] Включить SSL (Full strict)
- [ ] Настроить прокси (оранжевая облачная иконка)
- [ ] Записать NS-записи от Cloudflare

**Результат:** Домен работает через Cloudflare, SSL активен

---

### Шаг 2: VPS / Сервер (опционально, если не GitHub Pages)

- [ ] Выбрать хостинг: Masterhost / Hetzner / любой VPS за ~€3-5/мес
- [ ] Настроить SSH-доступ (ключ, не пароль)
- [ ] Установить Docker + docker-compose
- [ ] Настроить UFW (только 22, 80, 443)
- [ ] Установить fail2ban

**Результат:** VPS принят, SSH работает, Docker готов

---

### Шаг 3: Установка Architect

```bash
git clone https://github.com/dunaev/architect.git
cd architect
npm install
```

- [ ] Клонирован репозиторий
- [ ] Установлены зависимости
- [ ] `npm run dev` → локально открывается

**Результат:** Сайт работает локально на `localhost:4321`

---

### Шаг 4: CI/CD — GitHub Actions

- [ ] Создан `.github/workflows/deploy.yml`
- [ ] Настроен GitHub токен (repo → Settings → Secrets → ACTIONS_TOKEN)
- [ ] Push → авто-деплой на VPS
- [ ] Проверка: push в main → сайт обновился

**Результат:** CI/CD pipeline зелёный

---

### Шаг 5: Генерация превью (ComfyUI)

- [ ] ComfyUI установлен и запущен (локально, RTX 3070)
- [ ] Загружен базовый workflow (превью 1200×630px)
- [ ] Создан пресет "Social Preview"
- [ ] Протестирована генерация: текст → изображение

**Результат:** Превью для соцсетей генерируются одной командой

---

### Шаг 6: Базовая SEO-оптимизация

- [ ] title + description на каждой странице
- [ ] Open Graph теги (og:image, og:title, og:description)
- [ ] robots.txt (разрешить всё, указать sitemap)
- [ ] sitemap.xml (авто-генерация через Astro)
- [ ] Канонические URL (canonical)
- [ ] alt-тексты для всех изображений
- [ ] LCP < 2.5s (Lighthouse)

**Результат:** Google может индексировать сайт правильно

---

### Шаг 7: Аналитика (без Google)

- [ ] Установить Umami / Plausible на VPS (через Docker)
- [ ] Добавить скрипт на сайт
- [ ] Проверить: свой визит отображается
- [ ] Настроить дашборд

**Результат:** Аналитика работает, данные не уходят Google

---

### Шаг 8: Контент-календарь на 30 дней

- [ ] Определены 10+ тем (см. MARKETING-STRATEGY-M5.md)
- [ ] Распределены по каналам (X, Telegram, Dev.to, Habr)
- [ ] Каждой теме назначен формат
- [ ] Запланированы первые 3 публикации
- [ ] Созданы черновики

**Результат:** Контент-план на месяц готов, можно публиковать

---

### Шаг 9: SMM-пайплайн

- [ ] Определены каналы: X/Twitter, Telegram
- [ ] Создан визуальный шаблон для постов (бренд-кит)
- [ ] Настроен кросс-постинг (через n8n / вручную)
- [ ] Частота: X — 1-2/день, Telegram — 1-2/нед
- [ ] Первые 3 поста опубликованы

**Результат:** Соцсети активны, контент публикуется регулярно

---

### Шаг 10: Мониторинг + Бэкапы

#### Мониторинг
- [ ] Установлен Uptime Kuma (Docker)
- [ ] Добавлены проверки: сайт, API, SSH
- [ ] Алерты в Telegram (через Webhook/бот)

#### Бэкапы
- [ ] Настроен бэкап кода (git — уже работает)
- [ ] Настроен бэкап конфигов (cron + rsync/S3)
- [ ] Настроен бэкап БД (если есть)
- [ ] Протестировано восстановление

**Результат:** Если всё упадёт — восстановление за 30 минут
