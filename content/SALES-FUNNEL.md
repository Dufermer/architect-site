## 2. Воронка: AIDA

```
Осведомлённость → Интерес → Желание → Действие
(Awareness)      (Interest) (Desire)  (Action)
```

### Этап 1: Осведомлённость (Awareness)
**Каналы:** Twitter/X, Telegram, Dev.to, Habr, GitHub
**Цель:** Привлечь внимание к проблеме

| Канал | Формат | Пример | CTA |
|-------|--------|--------|-----|
| Twitter/X | Thread #buildinpublic | "Как мы заменили 5 сервисов одним open-source стеком" | 🔗 Ссылка на статью |
| Dev.to | Кейс-статья | "Building an Open-Source All-in-One Ecosystem" | ⭐ GitHub star |
| Telegram | Анонс-пост | "Запускаем Architect — open-source экосистему" | 💬 Вопрос к аудитории |
| GitHub | README / pinned repo | Репозиторий Architect | ⭐ Star + 👁 Watch |

**Метрики:** Охваты (impressions), переходы на сайт/GitHub, новые подписчики
**KPI W1:** 500 impressions, 50 кликов

### Этап 2: Интерес (Interest)
**Каналы:** Сайт (лендинг), GitHub, Telegram
**Цель:** Вовлечь, показать ценность

| Точка контакта | Что показываем | Формат |
|----------------|---------------|--------|
| Лендинг | Ценностное предложение + скриншоты/демо | Hero section + features |
| GitHub README | Архитектура, стек, quick start | Документация |
| Telegram | FAQ, Q&A, обсуждения | Посты + чат |
| Дайджест | Что сделано за неделю, road map | Пост |

**Лид-магниты (на этом этапе):**
1. **Чеклист** "SEO для сайта на Astro.js: 15 шагов до запуска" — скачать с сайта
2. **Гайд** "Open-source стек для веб-присутствия: от 0 до деплоя за день" — PDF
3. **Демо-доступ** — ссылка на live-версию Architect

**Метрики:** Время на сайте, глубина просмотра, скачивания магнитов
**KPI W1:** 20% от этапа 1 → 10 лид-магнитов

### Этап 3: Желание (Desire)
**Каналы:** Email (форма на сайте), Telegram личные сообщения, прямые демо
**Цель:** Конкретизировать интерес в потребность

| Действие | Что получает пользователь |
|----------|--------------------------|
| Оставил email | Получает чеклист + гайд + приглашение в Telegram |
| Участвует в Q&A | Ответы на вопросы, кейсы использования |
| Запросил демо | Live-демо с разбором под его задачу |

**CTA для каждого этапа:**
| Этап воронки | CTA | Где размещено |
|-------------|-----|---------------|
| Статья | "⭐ Star on GitHub" | Конец статьи, врезка |
| Чеклист | "📥 Скачать чеклист → [email]" | Popup / inline form |
| Гайд | "📖 Читать полный гайд" | Кнопка на лендинге |
| Демо | "🚀 Записаться на демо" | Кнопка в Hero / хедер |
| Telegram | "💬 Присоединиться к сообществу" | Все точки контакта |

**Метрики:** Соотношение warm лидов, запросы демо
**KPI W1:** 3+ теплых лида

### Этап 4: Действие (Action)
**Каналы:** GitHub (установка), сайт (демо), прямые контакты
**Цель:** Конверсия в установку / клиента

| Действие | Метрика | Условие успеха |
|----------|---------|---------------|
| Установка CLI | `npm create architect` | 3 активные установки M1 |
| Клонирование репозитория | `git clone` + stars | 30 stars M1 |
| Запрос кастомизации | Email / DM | 1–2 платных запроса M1 |

**Метрики конверсии (сквозные):**
```
Статья (500 просмотров)
  → GitHub (50 визитов = 10%)
    → Star (10 stars = 2% от просмотров)
      → Установка (3 установки = 0.6% от просмотров)
        → Активный пользователь (2 = 0.4%)
```

**KPI по месяцам:**

| Метрика | M1 | M2 | M3 |
|---------|-----|-----|-----|
| GitHub stars | 30 | 70 | 100 |
| Активные установки | 3 | 7 | 15 |
| Telegram подписчики | 50 | 150 | 300 |
| Лиды (email) | 10 | 30 | 50 |
| Конверсия статья→установка | 0.5% | 1% | 2% |

## 4. Лид-магниты

### Магнит 1: Чеклист "SEO для сайта на Astro.js: 15 шагов до запуска"

**Формат:** Markdown / Notion / Google Docs (позже PDF)
**Канал:** Форма email на лендинге

```
☐ Выбрать ключевые слова (long-tail, семантика)
☐ Настроить мета-теги (title, description, OG)
☐ Создать sitemap.xml (авто через Astro)
☐ Robots.txt (разрешить индексацию)
☐ Open Graph изображения (1200×630, шаблон)
☐ Canonical URLs (избежать дублей)
☐ JSON-LD Structured Data (Organization, Article)
☐ RSS Feed для блога
☐ Lighthouse Performance 90+
☐ Core Web Vitals: LCP < 2.5s, CLS < 0.1
☐ Mobile-first адаптив
☐ Внутренняя перелинковка статей
☐ Внешние ссылки + guest posts
☐ Google Search Console (подключить, отправить sitemap)
☐ Яндекс.Вебмастер (для RU аудитории)
```

### Магнит 2: Гайд "Open-source стек для веб-присутствия от 0 до деплоя"

**Формат:** Post / статья в Telegram
**Канал:** Telegram после вступления

Содержание:
1. Выбор VPS / хостинга
2. Docker + Nginx настройка
3. GitHub Actions CI/CD пайплайн
4. Cloudflare DNS + SSL
5. Astro.js + Tailwind базовая настройка
6. Первый деплой

### Магнит 3: Демо-доступ

**Формат:** Ссылка на live-версию Architect
**Канал:** Email после подтверждения интереса
**Дополнительно:** Приватный Telegram-канал для early adopters
