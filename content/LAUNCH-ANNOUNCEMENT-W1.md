[Видео/гифка превью 1200×630]

**TWEET 2/7**
The problem:
• Vercel starts at $20/mo and you don't control the infra
• Netlify is $19/mo with vendor lock-in
• WordPress is slow and insecure
• Managing your own VPS is a full-time job

We wanted: fast, open-source, under $5/mo, full control.

**TWEET 3/7**
The stack:

• Astro.js — static site, 95+ Lighthouse
• Cloudflare Pages — free CDN + SSL
• GitHub Actions — CI/CD on push
• ComfyUI + Stable Diffusion — AI previews
• Healthchecks.io — monitoring

Total: $1/mo (just the domain).

**TWEET 4/7**
Why Astro.js?
• Zero JS by default → pages load instantly
• Islands architecture → interactivity only where needed
• MDX content → write in Markdown, publish as HTML
• Built by a "shed" mentality → the right tool for content sites
