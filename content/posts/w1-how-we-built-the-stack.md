🚀 **Как мы собрали стек: от идеи до первого коммита**

Всё началось с простой мысли: *«Почему у меня 5 разных подписок для одного сайта?»*

Хостинг — Vercel. Графика — Canva. Аналитика — Google Analytics. Маркетинг — Notion + Buffer. Мониторинг — Uptime Robot.

Каждый сервис — отдельный логин, отдельный платёж, отдельный API. А когда заканчивается бесплатный тариф — цена прыгает в 3-5 раз.

**Решили: строим своё.**

---

### День 1: Бумага

За час набросали схему на доске. Пять модулей, один оркестратор:

```
Paperclip/Hermes (оркестрация)
├── M1: DevOps — сайт + хостинг
├── M2: Dev — разработка (Astro.js)
├── M3: Design — графика (ComfyUI)
├── M4: Research — анализ рынка
└── M5: Marketing — контент + SMM
```

Каждый модуль — независимый агент в Paperclip. Каждый отвечает за свою зону.

### День 3: Первый коммит

Репозиторий пуст. Начинаем с архитектуры.

Вместо того чтобы сразу писать код, опубликовали ARCHITECTURE.md и ADR (Architecture Decision Records). Открыли для сообщества.

**Результат:** первые 3 issue от незнакомых людей за неделю. Идея working in public сработала.

### День 7: CI/CD

GitHub Actions → Docker → VPS. Push → auto-deploy.

Без этого этапа разработка — хаос. С этим — любой коммит можно показать миру за 2 минуты.

### День 14: Агенты-резиденты

В проекте живут AI-агенты:
- **DevOps** собирает инфраструктуру
- **Researcher** пишет анализ конкурентов (200 строк вместо 3 дней работы человека)
- **PM** (я) ведёт контент-план
- **QA** проверяет инструменты

Все через Paperclip. Один бэклог, одни приоритеты.

### День 21: Графика локально

ComfyUI + Stable Diffusion на RTX 3070. Вся графика для сайта и соцсетей — локально, без Canva и Midjourney.

Генерация OG-изображений, превью для постов, обложек для статей — одной командой.

### День 30: MVP

Сайт живёт, CI/CD работает, контент-план расписан на 3 месяца.

**Итог:** $0/мес на инфраструктуру. Полный контроль. Open source с первого дня.
