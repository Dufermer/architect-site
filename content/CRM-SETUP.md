## 1. Структура Google Sheets

**Название таблицы:** `Лиды Архитектор`

| Колонка | Тип | Пример | Примечание |
|---------|-----|--------|------------|
| ID | Авто | L-001 | =ROW()-1 |
| Дата | Дата | 08.06.2026 | Авто-заполнение |
| Источник | Список | Twitter / Telegram / Habr / Email / Сайт | Выпадающий список |
| Имя / Контакт | Текст | @user / user@email.com | Телеграм юзернейм или email |
| Статус | Список | новый / тёплый / клиент / закрыт | Выпадающий список |
| Комментарий | Текст | Интересуется self-hosted стеком | Свободное поле |
| Следующее действие | Текст | Отправить чеклист | Что делаем дальше |
| Ответственный | Текст | PM / Lead Engineer | Кто обрабатывает |

**Дата-валидация (Data Validation):**
- Источник → Dropdown: Twitter, Telegram, Habr/VC, Dev.to, Email, Сайт, GitHub
- Статус → Dropdown: новый, тёплый, клиент, закрыт (потерян)

## 2. Пайплайн обработки лидов

```
Входящий → qualification → тёплый → демо → клиент
                               ↓
                         (воспитание → newsletter)
```

| Статус | Описание | Действие |
|--------|----------|----------|
| новый | Только появился, не квалифицирован | PM: проверить, написать в течение 24ч |
| тёплый | Проявил интерес, ответил | Отправить лид-магнит, договориться о демо |
| клиент | Установил / оплатил | Передать в поддержку |
| закрыт | Отказался / не ответил | Архивировать, причина отказа |

## 3. Инструкция по созданию

### Вариант A: Вручную через Google Sheets

1. Создать новую таблицу: sheets.new
2. Назвать: `Лиды Архитектор`
3. В A1–H1 ввести заголовки колонок (ID, Дата, Источник и т.д.)
4. Выделить Источник (C2:C) → Data → Data validation → Dropdown → список источников
5. Выделить Статус (E2:E) → Data validation → Dropdown: новый, тёплый, клиент, закрыт
6. ID формула: `=ROW()-1`
7. Дата формула: `=TODAY()`
8. Поделиться с командой

### Вариант B: Через Google Forms

1. Создать форму: forms.new
2. Поля: Имя, Контакт (email/tg), Комментарий
3. Привязать ответы к таблице `Лиды Архитектор`
4. Встроить форму на сайт (после интеграции блога)

## 4. Интеграция с каналами

| Канал | Как лид попадает в CRM |
|-------|----------------------|
| **Форма на сайте** | Автоматически через Google Forms → Sheets |
| **Twitter DM** | Ручной внос после ответа |
| **Telegram** | Ручной внос из личных сообщений |
| **Email** | Форма захвата → Forms → Sheets (авто) |
| **GitHub Issues** | Вручную, если issue выглядит как коммерческий интерес |

## 5. Метрики CRM

| Метрика | Цель M1 | Формула |
|---------|---------|---------|
| Лидов в неделю | >5 | COUNTIF(Статус="новый", Дата > today-7) |
| Конверсия в тёплые | >30% | тёплые / новые × 100 |
| Конверсия в клиенты | >10% | клиенты / новые × 100 |
| Время реакции | <24ч | среднее(createdAt → firstAction) |
| Каналы (топ) | — | COUNTIF по Источник |
