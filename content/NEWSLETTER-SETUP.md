# Email-рассылка: настройка и контент-план

## Цель
Регулярная email-рассылка (weekly digest) для сбора контактов и возврата аудитории на сайт.

## Варианты реализации

### Вариант A: Formspree (рекомендован)
- Бесплатно до 50 подписчиков
- Форма подписки на лендинге
- Интеграция через API
- Weekly digest через API

### Вариант B: Buttondown (альтернатива)
- Бесплатно до 1000 подписчиков
- Поддержка markdown
- API-driven публикация

### Вариант C: Прямая отправка через SMTP
- Полный контроль
- Требует SMTP-сервера
- Безопасность доставки

## Контент Weekly Digest

Формат:
- **Приветствие** (1 предложение)
- **Новости недели** (2-3 пункта)
- **Ссылка на статью** (Dev.to / блог)
- **Горячий вопрос для обсуждения**
- **Контакты** (Telegram, X/Twitter)

## Форма подписки (лендинг)

Поле: Email только
CTA: "Получить еженедельный дайджест"
Спасибо: "Проверьте почту — мы отправили подтверждение"

## Интеграция с сайтом

Форма подписки размещается на:
1. Хиро-секция лендинга
2. Конец каждой статьи
3. В sidebar блога

## План публикаций

| Неделя | Тема | Дата |
|--------|------|------|
| W1 | Старт экосистемы | ПТ 12.06 |
