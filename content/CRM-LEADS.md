## 2. Форма захвата (Google Forms)

**Поля формы:**
1. Имя / Nickname (текст, обязательное)
2. Email / Контакт (текст, обязательное)
3. Чем занимаешься? (выбор: `Инди-разработчик`, `Блогер`, `Предприниматель`, `Другое`)
4. Что ищешь? (выбор: `Готовый сайт`, `Стек для проекта`, `Вдохновение`, `Партнёрство`)
5. Откуда узнал? (выбор: `Twitter/X`, `Habr`, `Dev.to`, `Telegram`, `GitHub`, `Другое`)

**Связь:** Responses → Google Sheets (автоматически, встроенная функция Google Forms)

## 3. Статус-модель лида

```
New ──→ Warm ──→ Hot ──→ Client
  │        │       │
  └──→ Lost       │
           └──→ Archived
```

- **New** — первичный контакт (заполнил форму / написал в DM)
- **Warm** — проявил интерес (скачал лид-магнит, задал вопрос)
- **Hot** — готов к покупке / демо (запросил цену, просит установку)
- **Client** — активный пользователь / клиент
- **Lost** — потерян (не ответил за 14 дней)
- **Archived** — закрыт (выполнен или отклонён)

---

## 4. Процесс работы с лидом

1. **New** → в течение 24ч: отправить лид-магнит #1 (чеклист) + приветственное сообщение
2. **7 дней без ответа** → Follow-up: "Как успехи? Нужна помощь?"
3. **14 дней без ответа** → Lost
4. **Warm** → Отправить лид-магнит #2 (гайд) + приглашение в Telegram
5. **Hot** → Назначить демо / личную консультацию (CTO или PM)
6. **Client** → Передать в онбординг (GitHub + документация)
