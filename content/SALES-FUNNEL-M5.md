## 4. Этап 2: Интерес (Interest)

**Цель:** Показать ценность продукта, подогреть интерес

### Лид-магниты

#### Лид-магнит 1: Чеклист "10 шагов к self-hosted веб-присутствию"

- **Формат:** Google Docs / PDF
- **Раздача:** Telegram, форма на лендинге
- **Контент:**
  1. Выбор домена и настройка Cloudflare
  2. Развёртывание Astro.js через CLI
  3. CI/CD через GitHub Actions
  4. Генерация превью через ComfyUI
  5. Базовая SEO-оптимизация
  6. Аналитика без Google (Plausible / Umami)
  7. Контент-календарь на 30 дней
  8. SMM-пайплайн
  9. Мониторинг (Uptime Kuma)
  10. Бэкапы и безопасность

#### Лид-магнит 2: Гайд "Архитектура Architect: C4 диаграмма и ADR"

- **Формат:** Markdown / GitHub Gist
- **Раздача:** Dev.to, X/Twitter
- **Контент:** Разбор архитектуры модулей, схема, технические решения

#### Лид-магнит 3: Демо "Запусти свой сайт за 10 минут"

- **Формат:** Видео / Loom-запись
- **Раздача:** YouTube, Telegram
- **Контент:** Живая демонстрация: clone → install → deploy

## 6. Этап 4: Конверсия (Conversion)

**Цель:** Превратить посетителя в пользователя / установку

### Действия конверсии

| Действие | Описание | Метрика |
|----------|----------|---------|
| Установка | `git clone + npm install + npm run deploy` | Количество установок |
| GitHub star | Звезда репозитория | 100 stars (M1) |
| Подписка на Telegram | Вступление в канал | 200 подписчиков (M1) |
| Заполнение формы | Обратная связь / вопрос через форму | Конверсия формы > 5% |

### Путь конверсии

```
GitHub repo ──→ README с демо ──→ Установка
                   ↓
              Лендинг ──→ Форма / Чеклист ──→ Telegram
                   ↓
              Документация ──→ Wiki / Guides
```

### CTA на этапе конверсии

| Контекст | CTA |
|----------|-----|
| README.md | "⭐ Star us on GitHub" |
| После чеклиста | "Подпишись на канал → @dunaev_dev" |
| Ошибка установки | "Задай вопрос → Issues" |
| Демо-видео | "Попробуй сам → git clone" |
