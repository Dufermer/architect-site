# SMM Visual Brand Kit — Architect

## Назначение

Набор визуальных шаблонов для соцсетей (Telegram, X/Twitter), блога и маркетинговых материалов.
Основан на общем бренд-ките (brand-kit/BRAND-KIT.md), адаптирован для SMM-форматов.

## Типографика в SMM

| Элемент | Шрифт | Размер (на 800px шаблоне) | Вес |
|---------|-------|--------------------------|-----|
| Заголовок поста | Inter | 48–56px | Bold (700) |
| Подзаголовок | Inter | 32–40px | SemiBold (600) |
| Основной текст | Inter | 18–22px | Regular (400) |
| Мета / теги | Inter | 12–14px | Medium (500) |
| Цифры / статистика | Inter | 64–80px | Bold (700) |
| Источник / автор | Inter | 14px | Regular (400) |

### Масштабирование

Для других форматов размеры масштабируются пропорционально:
- **1200×675 (X):** ×1.5 относительно 800px базы
- **1080×1350 (Story):** ×1.35 по ширине

## Правила использования в SMM

1. **Не обрезать** логотип ближе чем на 20px от края
2. **Не менять** пропорции логотипа
3. **Градиент** — всегда слева направо или сверху вниз
4. **Текст** — не более 3 строк в заголовке (1200px: не более 4 строк)
5. **Контрастность** — текст должен быть читаем на фоне (проверять через WCAG AA)
6. **Анимации** — для Telegram/X использовать статичные PNG, для Stories — статичные превью
7. **Однородность** — все посты в ленте должны визуально принадлежать одному бренду
