## 1. Целевая аудитория и сегменты

### Первичные сегменты

| Сегмент | Описание | Боли | Каналы достижения |
|---------|----------|------|--------------------|
| **Инди-разработчики** | Соло-фаундеры, фрилансеры, делающие сайты для себя/клиентов | Хостинг дорогой, DevOps сложный, нужно быстро | Twitter/X, Dev.to, Telegram dev-чаты |
| **Open-source энтузиасты** | Разработчики, ценящие open-source, self-hosted | Не хотят vendor lock-in, хотят контролировать стек | GitHub, Twitter, Hacker News |
| **Технические предприниматели** | Основатели стартапов на ранней стадии | Бюджет $0, нужен быстрый запуск MVP | Product Hunt, LinkedIn, Twitter |
| **Технические блогеры** | Пишут технический контент, нужен простой сайт-визитка | Сложные CMS не нужны, хотят Markdown + быстрый сайт | Habr, Dev.to, Twitter |

| Сегмент | Когда | Подход |
|---------|-------|--------|
| **Агентства** | После M2 | Белый ярлык, мульти-сайты на одной инстанции |
| **Малый бизнес** | После M3 | Простой способ получить сайт без найма разработчика |

## 2. Воронка: 4 этапа

### Этап 1: Осведомлённость (Awareness)

**Цель:** Узнаваемость бренда Architect, привлечение внимания к проекту.

**Каналы:**
- Контент-маркетинг (Twitter/X, Telegram, Habr, Dev.to)
- GitHub (звёзды, README, discussions)
- Product Hunt (запуск M1W4)

**Контент на этом этапе:**
- Статьи: сборка open-source экосистемы, почему не Vercel, сравнение стеков
- Threads: #buildinpublic — ежедневные заметки о процессе
- Скриншоты/демо лендинга, генерации превью через Stable Diffusion

**Метрики:**
- Охваты (impressions)
- Переходы на сайт / GitHub
- Рост подписчиков в соцсетях
- GitHub stars

---

### Этап 2: Интерес (Interest)

**Цель:** Заинтересовать технической глубиной, показать ценность.

**Каналы:**
- Блог (поддомен blog.dunaev.dev)
- GitHub README + Docs
- Прямые ссылки из контента на лендинг

**Лид-магниты (см. раздел 3):**
- Чеклист "SEO для Astro.js" (лид-магнит #1)
- Гайд "Open-source стек веб-присутствия за $0" (лид-магнит #2)

**CTA на этом этапе:**
- "Читать полный гайд → скачать чеклист" (внизу статей)
- "Попробовать самому → GitHub" (в thread'ах)
- "Подписаться на новости → Telegram" (в хедере блога)

**Метрики:**
- Время на странице
- Глубина просмотра (2+ страниц)
- Клики по CTA
- Подписки на Telegram / email

---

### Этап 3: Рассмотрение (Consideration)

**Цель:** Доказать, что Architect — лучшее решение для их задачи.

**Каналы:**
- Демо-лендинг или live-пример
- Кейсы / разборы архитектуры (сравнение с Netlify, Vercel)
- Документация, API reference

**Лид-магниты (см. раздел 3):**
- Демо: живой сайт на Architect за 5 минут (лид-магнит #3)

**CTA на этом этапе:**
- "Запустить демо за 5 минут → [кнопка]" (на лендинге)
- "Посмотреть архитектуру → GitHub" (в технических постах)
- "Сравнить сами → таблица" (в сравнительных статьях)

**Метрики:**
- Количество попыток установки / демо
- GitHub clones / Docker pulls
- Вопросы в issues / discussions
- Посещаемость страниц сравнения

---

### Этап 4: Конверсия (Conversion)

**Цель:** Получить активную установку, подписку, демо-запрос.

**Каналы:**
- Лендинг (основная страница)
- GitHub (Quick start)
- Прямые обращения (Twitter DM, Telegram)

**CTA на этом этапе:**
- **Лендинг:** "Начать бесплатно → GitHub" (главный CTA)
- **Документация:** "Установить за 1 команду → curl ..."
- **Кейс-статья:** "Попробовать на своём проекте → [ссылка]"
- **Twitter DM:** "Расскажи, что собираешь — помогу с запуском"

**Метрики:**
- Установки (git clone / npm install)
- Активные пользователи
- Заполненные формы захвата
- Конверсия в тёплый лид

## 3. Лид-магниты

### Лид-магнит #1: Чеклист "SEO для Astro.js"

**Формат:** Google Docs / Markdown / PDF (скачивание по email)
**Цель:** Собрать email контактов технических блогеров и инди-разработчиков
**Содержание:**
- Мета-теги для Astro.js (+ компонент SEO)
- Open Graph изображения: автоматическая генерация
- Sitemap.xml и robots.txt
- Structured Data (JSON-LD)
- Performance: Lighthouse 90+ с Astro
- Core Web Vitals checklist
- RSS + канонические URL
**Путь:** Статья на Dev.to/Habr → кнопка "Скачать чеклист" → форма email → PDF
**Ответственный:** PM (создание), Designer (дизайн PDF-шаблона)

### Лид-магнит #2: Гайд "Open-source стек веб-присутствия за $0"

**Формат:** Статья / PDF
**Цель:** Привлечь технических предпринимателей с нулевым бюджетом
**Содержание:**
- Статический сайт на Astro.js (бесплатно)
- Хостинг на Cloudflare Pages (бесплатно)
- CI/CD через GitHub Actions (бесплатно)
- Мониторинг через Healthchecks.io/UptimeRobot (бесплатно)
- Аналитика через Cloudflare Analytics / Plausible (бесплатно)
- Домен: .dev за $12/год
- Итого: $1/месяц за полное веб-присутствие
**Путь:** Статья на Habr/Dev.to → ссылка "Полный гайд в PDF" → форма email → PDF
**Ответственный:** PM (написание)

### Лид-магнит #3: Демо "Живой сайт на Architect за 5 минут"

**Формат:** Интерактивное демо (GitHub template / StackBlitz / live URL)
**Цель:** Показать, как быстро работает Architect
**Содержание:**
- Forkнуть репозиторий-шаблон
- Заменить контент в Markdown
- Залить на Cloudflare Pages
- Получить рабочий сайт
**Путь:** GitHub → README → "Try in 5 minutes" → template repo → live demo URL
**Ответственный:** Lead Engineer (создание шаблона), PM (текст)

## 5. Структура лендинга (посадочная страница)

### Секции (сверху вниз)

1. **Hero**
   - Заголовок: "Собери open-source экосистему для своего сайта"
   - Подзаголовок: "Astro.js + Cloudflare + ComfyUI = быстрый, красивый, бесплатный сайт"
   - CTA: "Начать бесплатно → GitHub"
   - Визуал: скриншот лендинга / схема архитектуры

2. **Проблема**
   - "Vercel дорогой, WordPress сложный, DevOps отнимает время"
   - "Что если собрать стек, который работает бесплатно и ты всё контролируешь?"

3. **Решение**
   - Три колонки: Статика (Astro.js) + Хостинг (Cloudflare) + AI (ComfyUI)
   - Каждая колонка: иконка → короткое описание → "почему это важно"

4. **Как это работает** (3 шага)
   - Шаг 1: Fork → заменить контент
   - Шаг 2: Настроить CI/CD (автоматически)
   - Шаг 3: Опубликовать на свой домен
   - Визуал: простая схема/гифка

5. **Для кого**
   - Инди-разработчики
   - Технические блогеры
   - Open-source проекты
   - (иконка + 1 предложение на каждый)

6. **Сравнение** (таблица)
   | | Architect | Vercel | Netlify | WordPress |
   |---|---|---|---|---|
   | Цена | $0/мес | от $20 | от $19 | от $15 |
   | Open-source | ✅ | ❌ | ❌ | ✅ |
   | Self-hosted | ✅ | ❌ | ❌ | ✅ |
   | CI/CD | ✅ | ✅ | ✅ | ❌ |
   | AI-превью | ✅ | ❌ | ❌ | ❌ |

7. **Social Proof**
   - GitHub stars counter (live badge)
   - "Используется проектами: ..."
   - Twitter mentions / testimonials

8. **CTA** (повтор)
   - "Готов попробовать? → GitHub"
   - "Нужна помощь? → Telegram"

## 6. Метрики конверсии (KPI на каждый этап)

|---------|------------|----------------|

| **KPI:** Переход на Consideration (клоны GitHub/демо) | >30/мес | GitHub clones, демо form |
