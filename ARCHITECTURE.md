# Архитектура единой системы (проект Architect)

## Цель
Построить интегрированную систему, объединяющую управление сайтом и хостингом,
разработку, производство графики/видео, аналитику рынка и маркетинг.
API-driven модульная архитектура, управляемая через Paperclip-агентов.

**Критерии MVP:**
1. Сайт доступен по домену (dunaev.dev) с заглушкой/лендингом

3. ComfyUI генерирует первое изображение
4. Хотя бы один маркетинговый канал активен
5. Бэкапы настроены

## 6. Принципы

1. **Offline-first, local-primary** — всё работает на локальном железе
2. **API-driven** — модули общаются через API Paperclip
3. **Organic growth** — агенты нарабатывают навыки через реальные задачи
4. **Safety** — никаких правок node_modules и ui-dist продакшена
5. **Backward compatibility** — изменения обратимы через API/плагины
